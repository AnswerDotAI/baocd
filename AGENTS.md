# Project

- This project is a Python BPL port of [advent-of-code-data](https://github.com/wimglenn/advent-of-code-data/tree/main). We only reproduce `get_puzzle`, `Puzzle` and `Puzzle.submit` in this repo. 
- Keep the code as simple as possible using only `basedpl`. 
- Only use `fastcore` for tests
- Run `nbdev-prepare` before pushing anything.

# Import conventions

- Always import BasedPL with `from basedpl import *`.
- Always import fastcore with `from fastcore.all import *`.

# BPL conventions

- No whitespace between `|`. 
- Use glyphs to create the most compact representation that is possible.
